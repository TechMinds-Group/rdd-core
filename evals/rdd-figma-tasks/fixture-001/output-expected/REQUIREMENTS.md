# REQUIREMENTS.md

## 5. Regras de Negócio

**RN-010** [confirmado] — O sistema deve permitir o agendamento de banho para o animal,
com data, horário e serviço escolhidos pelo tutor.

**RN-011** [confirmado] — O sistema deve exibir a lista de próximos agendamentos do tutor,
ordenada por data crescente.

**RN-012** [confirmado] — O tutor deve poder cancelar um agendamento futuro.

## 8. Casos de Uso

- UC-03: Tutor agenda um banho para seu animal (RN-010, RN-011).
