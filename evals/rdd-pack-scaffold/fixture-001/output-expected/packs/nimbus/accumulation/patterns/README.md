# Accumulation — Patterns (Nimbus)

Padrões reutilizáveis extraídos de retrospectivas dos projetos Nimbus
(processo, arquitetura, código, UI, teste, dados). Ao acumular o primeiro
padrão, criar o `INDEX.md` nesta pasta.

- Acumulado no repo do pack — NUNCA instalado no runtime (IMP-116).
- Ponte de contribuição — padrão que se revelar genérico → generalizar e
  abrir PR no core (conteúdo neutro, sem dado de cliente).
