# Glossário do Usuário — Bloqueios Sanitários

> Linguagem do dia a dia de quem usa o sistema.

| Termo | O que significa para você |
|---|---|
| Produtor | A pessoa ou empresa rural que pode ser bloqueada |
| Bloquear | Impedir que o produtor emita GTA até resolver o problema sanitário |
| Motivo | O texto que explica por que o bloqueio está sendo aplicado (obrigatório) |
| Encerrar | Fechar o bloqueio quando o problema foi resolvido — precisa do motivo do encerramento |
| Histórico | A lista de tudo que aconteceu com um bloqueio: quando foi criado e quando foi encerrado |
| "Este produtor já possui um bloqueio ativo" | Mensagem que aparece se tentar bloquear quem já está bloqueado |
