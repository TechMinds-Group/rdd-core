# Transcrição — reunião com requisitos totalmente claros

**Data:** 21/09/2026
**Participantes:** Victor (analista), Marcos (PO sanitário)

**Marcos:** Duas regras fechadas do jurídico para o bloqueio:

Primeira: quando o operador aplicar um bloqueio, o sistema grava data,
hora e o usuário que aplicou — sempre.

Segunda: se o produtor já tiver bloqueio com status ativo, o sistema
recusa o novo bloqueio e mostra a mensagem "Este produtor já possui um
bloqueio ativo". Nada de termo vago, a mensagem é exatamente essa.

**Victor:** Casos de borda?

**Marcos:** Cobertos: bloqueio encerrado não impede re-bloqueio, e a
recusa não grava novo registro. Quem executa a recusa é o sistema.
