# <Org> Infra
Setup do MCP Hostinger para a org: a VPS de produção roda na Hostinger e o
rdd-devops precisa operar VPS/DNS/domínios via API (rdd-vps-setup,
rdd-vps-troubleshoot). O MCP Hostinger ainda não está configurado — pedir o
setup ao operador. Autenticação deve ser OAuth pelo TUI (nunca token no chat
ou em arquivo).
